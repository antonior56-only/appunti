Impostazioni

Intelligenza Artificiale (Gemini)

Serve solo per la funzione "Aiutami con l'AI". Genera la chiave su Google AI Studio. La chiave viene salvata in questo browser. Quando usi l'AI, il testo dell'appunto viene inviato a Gemini.

Backup su file

Salva o ripristina tutti gli appunti tramite un file .json sul dispositivo.

Importa da Google Keep

Esporta i tuoi appunti da Google Takeout (seleziona solo Keep), estrai lo .zip e scegli i file .json della cartella "Keep". Vengono importati testo, liste da spuntare, etichette e lo stato fissato/archiviato (le immagini no).

Importa da Samsung Notes

In Samsung Notes apri una nota, scegli Salva come file → File di testo, poi seleziona qui uno o più file .txt. Ogni file diventa un appunto modificabile; il nome del file viene usato come titolo. Le righe con caselle ☐/☑ o [ ]/[x] diventano una lista da spuntare. Immagini, disegni, audio e formattazione non sono presenti nel file di testo.

Backup automatico su cloud (JSONBin)

Crea una Access Key su jsonbin.io con permessi di creazione, lettura e aggiornamento dei bin. Inserisci un Bin ID esistente oppure lascialo vuoto: l'app creerà un nuovo bin privato con i tuoi appunti. Dopo la configurazione, ogni modifica verrà sincronizzata automaticamente. Se due dispositivi modificano lo stesso appunto, l'app conserva una copia del conflitto.
